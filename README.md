## English

### What is this?

**JJ Skills** is a private registry of all the skills taught to the opencode AI assistant by the user. Each skill lives in `skills/<skill-name>/` with its `SKILL.md` and supporting files.

### Why it exists

When working with an AI coding assistant (opencode), you often teach it specific workflows, platform quirks, and verified recipes. Without a registry, those lessons are lost between sessions. This repository keeps them organized, versioned, and reusable across projects and machines.

### Structure

```
skills/
  <skill-name>/
    SKILL.md
    ...supporting files
```

### Skills included

Skills cover: social messaging (Bale, Rubika, Eitaa, Soroush Plus), karpathy guidelines, memory bank, browser-use, and more.

## فارسی

### این چیست؟

**JJ Skills** یک رجیستری از تمام مهارت‌هایی است که به دستیار هوش مصنوعی opencode توسط کاربر آموزش داده شده. هر مهارت در پوشهٔ `skills/<skill-name>/` با فایل `SKILL.md` و فایل‌های پشتیبانی آن قرار دارد.

### چرا به وجود آمد؟

هنگام کار با یک دستیار کدنویسی هوش مصنوعی (opencode)، اغلب گردش‌کارها، ویژگی‌های پلتفرم و دستورالعمل‌های تأییدشده را به آن آموزش می‌دهید. بدون یک رجیستری، این درس‌ها بین نشست‌ها از بین می‌روند. این ریپازیتوری آن‌ها را سازمان‌دهی، نسخه‌بندی و قابل استفادهٔ مجدد در پروژه‌ها و ماشین‌های مختلف نگه می‌دارد.

### ساختار

```
skills/
  <skill-name>/
    SKILL.md
    ...فایل‌های پشتیبانی
```

### مهارت‌های موجود

مهارت‌ها شامل: پیام‌رسانی اجتماعی (بله، روبیکا، ایتا، سروش پلاس)، دستورالعمل‌های کارپاتی، بانک حافظه، browser-use و بیشتر.
